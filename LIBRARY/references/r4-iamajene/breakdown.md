Every 84 frames (2.8 s) the same cell plays: a slash command is typed against an attached talking-head clip, a dot-matrix reveal drops the finished edit into a chat card, the card grows to full-bleed for about 0.7 s, then a hard cut resets to a fresh chat for the next command. Mood: calm, dark, premium tool demo, no talking, carried by a steady music loop. Audience: creators and coaches who would buy an AI editing pack. Recognisable moves: the fixed 84-frame command -> reveal -> full-bleed cell, the interface as the hook (no face, no title, key-pop typing), and the dot-matrix "render" reveal.
