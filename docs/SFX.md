# Sound libraries

`LIBRARY/sfx/index.json` lists 309 sounds with category, length, hit time, level and licence. `studio sfx find` and
`studio mix` use only the ones present on the machine, so the studio works before any download.

| Sonniss GDC 2026, curated | 130 | Each person downloads the bundle (below) | Sonniss GDC 2026 licence v2.0 |

## Why Sonniss is not in the repository

Its licence allows commercial use without attribution but forbids redistributing the raw files (and AI training).
A shared repository would redistribute them, so each person downloads the free bundle and accepts the licence
themselves. The curation is code: `studio sfx import` keeps only the editing-relevant libraries (UI, whooshes,
impacts, drops, risers, paper, typing, cartoon, glitch, booms...) and leaves ambiences in the zips. Run against the
2026 zips it extracts the same 129 files the index describes (355 MB, from 7.47 GB of zips; checked 2026-10-29). The
index's 130th Sonniss entry is one hand-picked file (`sonniss_selected/OBJMisc_ScratchCard_SurfaceWipe_04_...wav`,
from a library the import filter skips); copy it from the zip into `SFX/_downloads/sonniss_selected/` if wanted.

## Add Sonniss (optional, about 7.5 GB download)

1. Download the five "GDC 2026 Game Audio Bundle" zips from https://gdc.sonniss.com (free) into
   `SFX/_downloads/sonniss_gdc2026/`.
2. Extract the editing-relevant part:

   ```bash
   node tools/studio/studio.mjs sfx import SFX/_downloads/sonniss_gdc2026/*.zip --to SFX/sonniss_gdc2026
   ```

   (Windows Command Prompt does not expand `*`: list the five zip paths.)
3. The existing index already describes these files, so `studio sfx find` picks them up at once. If you import
   with different options, rebuild it: `node tools/studio/studio.mjs sfx index`.
4. The zips can then be deleted to free 7.5 GB; everything stays out of git either way.

## Adding your own sounds

Put a folder of WAV/OGG files in `SFX/<name>/`, note its licence, and run `studio sfx index`. Commit the index only
if every teammate will have the same files; otherwise their `sfx find` simply skips the missing ones.
